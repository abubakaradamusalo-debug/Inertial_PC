# MATLAB Codes for Numerical Experiments

This repository contains the complete MATLAB implementations used for the numerical experiments reported in the accompanying research paper on algorithms for variational inequality problems.

All MATLAB codes were written and implemented by **Dr. Abubakar Adamu**.

## Description

The repository provides individual `.m` files implementing the seven algorithms compared in the paper:

* PASY Algorithm
* CTC Algorithm
* DCZR Algorithm
* M Algorithm
* TQY Algorithm
* TVC Algorithm
* T Algorithm

Each algorithm is implemented in a separate MATLAB file to allow independent testing and easy comparison of their performance.

## Purpose of the Codes

The codes are provided to:

* Reproduce the numerical results reported in the paper.
* Facilitate comparison of different algorithms for solving variational inequality problems.
* Serve as a reference implementation for researchers working in optimization, fixed point theory, and variational inequality problems.

## Structure

Each MATLAB file contains:

* The full implementation of a specific algorithm.
* Parameter initialization used in the experiments.
* Iterative procedures for computing approximate solutions.
* Stopping criteria based on iteration limits and error tolerance.

Some implementations also output iteration data to text files for analysis and visualization.

## Requirements

The codes were developed and tested using **MATLAB**.
No additional toolboxes are required beyond standard MATLAB functions.

## How to Run the Codes

1. Download all `.m` files in this repository.
2. Save all the files in the **same folder**.
3. Open MATLAB and navigate to that folder.
4. Run the main script:

```
run_all_algorithms.m
```

The script will automatically execute all the algorithms for the different problem dimensions specified in the code.

### Output

* The **iteration counts and CPU time** for each algorithm will be displayed in the MATLAB **console**.
* Any additional outputs generated by individual algorithm files will be **saved separately** for each algorithm.
* The script also generates a **LaTeX table** summarizing the numerical results for all algorithms and problem dimensions.
